# Test Files for convert2mkv

This repository contains dummy test files designed to validate the functionality of the [convert2mkv](https://codeberg.org/pwshAgyjkcrg761/convert2mkv-temp) script.

## Purpose
These files are intended for development and testing use only. Use them to verify that the script correctly identifies video containers, matches external subtitles, and performs remuxing operations without modifying your personal media collection.

## How to use
1. Clone or download the `test files` directory to a separate testing location.
2. Run [convert2mkv](https://codeberg.org/pwshAgyjkcrg761/convert2mkv-temp) against this directory.
3. Review the output to ensure the script correctly remuxes containers and attaches external subtitles as expected.

*Note: These files do not contain actual media content.*
